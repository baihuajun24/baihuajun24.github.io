01 / Research

A systems view of inference.

From individual tokens to multi-step agents, I study where inference spends time and how to reduce that cost. Three complementary lines of work connect this agenda.

  1. 01

    Token generation

    Draft more efficiently

    Parallel drafting with a reusable, low-cost draft model.

  2. 02

    Model reasoning

    Avoid redundant reasoning

    Use the draft model’s own signals to guide when reasoning can stop.

    SpecExit ↗
  3. 03

    Agent execution

    Overlap reasoning and tools

    Anticipate tool calls so useful work can begin before reasoning ends.

Self-Speculative Forking to Accelerate Agentic LLM Inference

Huajun Bai, Weiwei Lv, Huichuan Zheng, Youyou Lu, Jiwu Shu

A training-free controller that anticipates an agent’s tool call and starts execution while reasoning continues. Shared prefixes keep speculation lightweight; verification determines whether to reuse the result or fall back.
